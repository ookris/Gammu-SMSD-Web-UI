# Ikony – Solar Icon Set

Ikony w tym katalogu pochodzą z zestawu **Solar Icon Set** (styl *linear*), autor: **480 Design**
(https://www.figma.com/community/file/1166831539721848736), pobrane z https://icon-sets.iconify.design/solar/.

Licencja: **Creative Commons Attribution 4.0 International (CC BY 4.0)** –
https://creativecommons.org/licenses/by/4.0/

Pliki nie były modyfikowane poza usunięciem atrybutów `width`/`height` (rozmiar ustala CSS).
Atrybucja jest wyświetlana w stopce panelu i w README projektu.
